# Bo Ban Giao: [MOD-LMS-04][UC-LMS-09] API Export goi khoa hoc .imscc kem ACCEES-LOM (v1.0)

- Endpoint chính: `POST /lms/api/rest/v2/local_accees_imscp/courses/{courseid}/export`
- Endpoint tải artifact: `GET /lms/api/rest/v2/local_accees_imscp/exports/{token}`
- Scope OAuth 2.0: `local_accees_imscp:imscp:export`
- Capability: `local/accees_imscp:export`
- Quy chuẩn: IMS Common Cartridge 1.1.0 / IMSCP kem IEEE LTSC LOM (ACCEES-LOM v1.0 voi 5 core custom fields + 9 nhom metadata LOM)
- Cau hinh route: `cookies: false` (stateless API, khong khoi tao cookie phien)

---

## 1. Danh muc Fixtures & File Mau

- `ACCEES-CS101-v1.0.imscc`: File package `.imscc` thuc te duoc xuat tu khoa hoc Moodle ID 35 (`ACCEES-CS101`), chua day du `imsmanifest.xml` kem metadata LOM va cac tai nguyen hoc tap HTML trong `webcontent/`.
- `sample_export_request.json`: Payload JSON mau yeu cau export voi `delivery: "download_url"` va `lom_override`.
- `sample_export_binary_request.json`: Payload JSON mau yeu cau xuat truc tiep file nhi phan voi `delivery: "binary"`.
- `sample_response_200.json`: Payload phan hoi HTTP 200 OK thuc te chua `download_url`, `checksum_sha256`, `size_bytes`, `filename`, `expires_at`.
- `sample_error_400.json`: Phan hoi HTTP 400 khi `courseid` khong hop le (`INVALID_PARAMETER`).
- `sample_error_401.json`: Phan hoi HTTP 401 khi thieu hoac sai Bearer token (`UNAUTHORIZED`).
- `sample_error_403.json`: Phan hoi HTTP 403 khi token khong co capability tren khoa hoc (`FORBIDDEN`).
- `sample_error_404.json`: Phan hoi HTTP 404 khi khoa hoc hoac artifact token khong ton tai (`COURSE_NOT_FOUND`).


### 3.4 Error Cases: HTTP 400 / 401 / 403 / 404

#### Case 1: HTTP 400 INVALID_PARAMETER (courseid = 0)
**Lenh curl:**
```bash
curl -i -X POST http://meko.localhost/lms/api/rest/v2/local_accees_imscp/courses/0/export \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"delivery": "download_url"}'
```
**Response JSON (400 Bad Request):**
```json
{
  "error": {
    "code": "INVALID_PARAMETER",
    "message": "Invalid courseid parameter: must be a positive integer",
    "details": {
      "courseid": "0"
    }
  }
}
```

#### Case 2: HTTP 401 UNAUTHORIZED (Thieu hoac sai Bearer token tren POST export)
Kiem tra trang thai xac thuc `api_token_id` / `oauth_user_id` truoc khi check capability, dam bao tra 401 chu khong phai 403 theo dung spec muc 3.2.

**Lenh curl:**
```bash
curl -i -X POST http://meko.localhost/lms/api/rest/v2/local_accees_imscp/courses/35/export \
  -H "Content-Type: application/json" \
  -d '{"delivery": "download_url"}'
```
**Response JSON (401 Unauthorized):**
```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Missing or invalid Bearer authentication token",
    "details": []
  }
}
```

#### Case 3: HTTP 401 UNAUTHORIZED (Thieu Bearer token tren GET /exports/{token})
**Lenh curl:**
```bash
curl -i -X GET http://meko.localhost/lms/api/rest/v2/local_accees_imscp/exports/token-23e8bbbe9ffdd431fd5ea69683bf6ef8
```
**Response JSON (401 Unauthorized):**
```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Missing or invalid Bearer authentication token",
    "details": []
  }

```
