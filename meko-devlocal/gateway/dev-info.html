MEKOSOFT Local Dev Environment

meko.localhost — Docker Unified Stack

Liferay 7.4 GA132 (CMS + TMS) + Moodle 5.3 LTS (LMS) + PostgreSQL 17 + Nginx Gateway

CMS (Liferay /) Mở TMS (/tms) Mở LMS (/lms)
Lưu ý khởi động lần đầu: Moodle và Nginx sẵn sàng trong ~15 giây. Liferay 7.4 GA132 cần khoảng 2–3 phút để khởi tạo schema PostgreSQL và OSGi bundle lần đầu. Nếu vào / hoặc /tms thấy trang này, hãy đợi thêm 1–2 phút rồi F5.
